# AI 颜值评分 — 开发问题总结

本文档记录在 **Windows WSL2 + 红米 Android + Expo Go** 环境下开发本项目时遇到的问题、原因与解决方案，供后续开发或换机器时参考。

---

## 1. 项目初始化

### 问题：WSL 下 `create-expo-app` 失败

```
WSL 1 is not supported. Please upgrade to WSL 2 or above.
Could not determine Node.js install directory
```

**原因：** 沙箱环境或 WSL 版本/Node 路径识别异常。

**解决：** 使用完整权限重新执行：

```bash
npx create-expo-app@latest . --template blank-typescript --yes
```

---

## 2. Metro 打包失败

### 问题 A：缺少 `babel-preset-expo`

```
code: 'MODULE_NOT_FOUND'
TypeError: Cannot read properties of undefined (reading 'transformFile')
```

**原因：** `babel.config.js` 引用了 `babel-preset-expo`，但未安装。

**解决：**

```bash
npm install babel-preset-expo --legacy-peer-deps
```

并在 `.npmrc` 中增加：

```
legacy-peer-deps=true
```

### 问题 B：缺少 `react-native-worklets`

```
Cannot find module 'react-native-worklets/plugin'
```

**原因：** `react-native-reanimated` v4 依赖 worklets 插件。

**解决：**

```bash
npx expo install react-native-worklets
```

### 问题 C：Expo SDK 57 依赖版本不匹配

```
Unable to resolve module react-native/Libraries/Renderer/shims/ReactNative
```

**原因：** `react-native-gesture-handler`、`reanimated` 等版本与 SDK 57 不一致。

**解决：**

```bash
npx expo install --fix
```

### 问题 D：`StyleSheet.absoluteFillObject` 报错

**原因：** React Native 0.86 改为 `StyleSheet.absoluteFill`。

**解决：** 全局替换 `absoluteFillObject` → `absoluteFill`。

## 3. AI 接口配置

### 问题：需使用 OpenRouter + DeepSeek，而非 OpenAI 直连

**需求：** 使用 OpenRouter API Key 和 DeepSeek 视觉模型。

**解决：**

- 环境变量改为 `EXPO_PUBLIC_OPENROUTER_API_KEY`
- API 地址：`https://openrouter.ai/api/v1/chat/completions`
- 模型：`deepseek/deepseek-v4-flash-vision-exp`（支持图片）
- `.env` 已加入 `.gitignore`，勿提交密钥

**安全提醒：** API Key 曾在对话中明文出现，建议在 OpenRouter 后台轮换密钥。

## 4. 红米真机 + Expo Go 连接问题

开发环境：**WSL2** 内跑 Metro，**红米** 安装 Expo Go，通过 WiFi 连接。

### 问题 A：`npx expo start --tunnel` 失败

```
CommandError: failed to start tunnel
remote gone away
```

**原因：** Expo 内置 Ngrok 版本较旧，服务不稳定；国内网络也可能加剧失败。

**解决（按优先级）：**

| 方案 | 适用场景 |
|------|----------|
| USB + `adb reverse` | 有数据线，最稳 |
| WSL 镜像网络 + `--lan` | 长期开发 |
| Windows 端口转发 + `--lan` | 无 USB、未开镜像 |
| 重试 `--tunnel --clear` | 碰运气 |

---

### 问题 B：扫二维码后 Expo Go 一直转圈

**现象：** 终端显示 `Metro: exp://127.0.0.1:8081`，扫码后无限加载。

**原因：** `127.0.0.1` 是手机本机地址，不是电脑。未做 `adb reverse` 时手机连不到 WSL 里的 Metro。

**解决：**

```powershell
# Windows PowerShell
adb reverse tcp:8081 tcp:8081
```

```bash
# WSL
npx expo start --localhost
```

手机输入：`exp://127.0.0.1:8081`

---

### 问题 C：手动输入 `exp://192.168.1.100:8081` 报错

**现象：** Expo Go 提示 "something went wrong"。

**原因：**

1. `192.168.1.100` 是文档**示例 IP**，非本机地址
2. 本机实际 WiFi IP 为 **`192.168.0.105`**（以 `ipconfig` 为准）
3. WSL 内 Metro 监听 `172.17.x.x`，手机无法直接访问，需 Windows 端口转发

**解决步骤：**

**① 管理员 PowerShell 配置端口转发：**

```powershell
netsh interface portproxy add v4tov4 listenport=8081 listenaddress=0.0.0.0 connectport=8081 connectaddress=172.17.12.43
netsh advfirewall firewall add rule name="Expo Metro 8081" dir=in action=allow protocol=TCP localport=8081
netsh interface portproxy show all
```

> `172.17.12.43` 为 WSL IP，以 `wsl hostname -I` 实际输出为准。

**② WSL 启动：**

```bash
npx expo start --lan
```

**③ 先在 Windows 浏览器验证：**

```
http://192.168.0.105:8081
```

必须返回页面（HTTP 200）后，手机才能连。

**④ 手机 Expo Go 手动输入（勿扫 172.x 二维码）：**

```
exp://192.168.0.105:8081
```

**辅助脚本：** 项目 `scripts/setup-wsl-port.ps1` / `setup-wsl-port.bat`（需管理员运行）。

---

### 问题 D：浏览器打不开 `http://192.168.0.105:8081`

**原因：** 未执行端口转发，或 PowerShell 非管理员导致 `netsh` 静默失败。

**验证：**

```powershell
netsh interface portproxy show all
# 应看到：0.0.0.0 8081 → 172.17.x.x 8081
```

WSL 内 Metro 正常时，`http://172.17.12.43:8081` 在 Windows 浏览器应可访问。

## 5. WSL2 网络原理（便于排查）

```
手机 ──WiFi──► 192.168.0.105:8081 (Windows)
                    │
                    │ portproxy（需管理员配置）
                    ▼
              172.17.x.x:8081 (WSL Metro)
```

- WSL 终端二维码显示 `172.17.x.x` → **手机不能直接扫**
- `--tunnel` 走 Ngrok 公网 → 常失败
- `--localhost` + `adb reverse` → USB 最稳
- `networkingMode=mirrored` → 二维码直接显示 `192.168.x.x`，最省心

**WSL 镜像网络配置（`.wslconfig`）：**

```ini
[wsl2]
networkingMode=mirrored
hostAddressLoopback=true
```

配置后 `wsl --shutdown` 重启 WSL。

## 6. 功能与平台限制

### 实时扫描人脸打分

- **已实现：** 前置摄像头 + 每 2 秒采样 + 实时本地分数 + 定格后 DeepSeek 深度分析
- **限制：** Expo Go 无原生 ML Kit，无法做人脸关键点跟踪；实时分为本地快速算法，非医学级检测
- **进阶：** 人脸框跟随需集成 ML Kit + 自定义 Development Build（不能再用 Expo Go）

### 上架 App Store 是否必须 Mac

- **本地 Xcode 打包：** 需要 Mac
- **EAS Build 云端打包：** Windows/WSL 即可发起，无需 Mac
- **跨机流程：** Windows 开发 → Git 同步 → Mac 或 EAS 打包（见 README「跨机开发 & 打包上架」）

## 8. 问题排查清单

连不上真机时，按顺序检查：

- [ ] WSL 里 Metro 是否在跑（`npx expo start --lan`）
- [ ] 手机与电脑是否同一 WiFi（勿用移动数据）
- [ ] 是否误用示例 IP（应用 `ipconfig` 真实 IPv4）
- [ ] `netsh interface portproxy show all` 是否有 8081 规则
- [ ] Windows 浏览器能否打开 `http://<电脑IP>:8081`
- [ ] 是否扫了 `172.x` 或 `127.0.0.1` 的码（应手动输入 `exp://电脑IP:8081`）
- [ ] USB 方案是否执行了 `adb reverse`
